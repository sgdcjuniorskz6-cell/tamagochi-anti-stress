# Requirements: Интерактивный тамагочи-антистресс

**Defined:** 2026-07-22
**Core Value:** Расслабление и радость от взаимодействия — питомец откликается на заботу живыми реакциями.

## v1 Requirements

### Базовый питомец

- [x] **PET-01**: Питомец отображается в браузере (Emoji) с базовыми состояниями
- [x] **PET-02**: Питомец имеет праздный режим (idle animation) — легкое покачивание/дыхание

### Реакции

- [x] **PET-03**: Реакция на клик — смех/прыжок с CSS-анимацией
- [x] **PET-04**: Механика кормления — выбор еды, питомец ест с анимацией
- [x] **PET-05**: Поглаживание (mousedown/move) — питомец мурлычет, меняет表情

### Настроение

- [ ] **PET-06**: Система настроения — питомец грустит/радуется со временем
- [ ] **PET-07**: Взаимодействие поднимает настроение, бездействие — опускает

### Звуки

- [ ] **PET-08**: Звук реакции на клик (Web Audio API)
- [ ] **PET-09**: Звук кормления
- [ ] **PET-10**: Звук поглаживания
- [ ] **PET-11**: Фоновый звук/тишина в зависимости от настроения

### UI/UX

- [ ] **PET-12**: Антистресс-дизайн (мягкие пастельные цвета, скругления)
- [x] **PET-13**: Кнопки/UI для кормления (выбор еды)
- [ ] **PET-14**: Индикатор настроения (визуальный статус)

## v2 Requirements

Deferred to future version.

- **PET-15**: Несколько видов питомцев на выбор
- **PET-16**: Мини-игры (бросание мячика, ловля)
- **PET-17**: Статистика за сессию
- **PET-18**: Смена темы оформления (день/ночь)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Сохранение состояния | Только сессионный опыт |
| Мобильное приложение | Только веб-версия |
| Многопользовательский режим | Только соло |
| Прогрессия/уровни | Чистый антистресс, без геймификации |
| Бэкенд | Полностью клиентское приложение |
