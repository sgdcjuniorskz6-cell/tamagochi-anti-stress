# Phase 1 Context: База + Реакция на клик

## Design Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Чистый HTML/CSS/JS | Zero dependencies, открывается файлом в браузере | ✓ Good |
| Emoji для питомца | Минимальный код, максимум выразительности | — Pending |
| Web Audio API для звуков | Без внешних аудиофайлов, синтезированные звуки | — Pending |
| Плавные CSS-анимации | transition + @keyframes без библиотек | — Pending |
| Пастельная цветовая палитра | Антистресс-эффект, мягкие тона | — Pending |

## Phase Goal

Питомец отображается на странице и реагирует на клик с анимацией.

## Requirements

- PET-01: Питомец отображается (Emoji) с базовыми состояниями
- PET-02: Idle-анимация (легкое покачивание/дыхание)
- PET-03: Реакция на клик — смех/прыжок с CSS-анимацией

## Success Criteria

1. При открытии index.html в браузере виден питомец
2. Питомец имеет idle-анимацию (покачивание)
3. При клике на питомца — анимация прыжка/смеха
4. Анимации плавные (transition 200-300ms)
5. Дизайн приятный, пастельные тона
