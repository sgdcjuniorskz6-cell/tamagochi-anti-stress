# Phase 2 Context: Кормление + Поглаживание

## Design Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Emoji-еда | Визуально понятно, zero deps | — Pending |
| Кнопки под питомцем | Интуитивный UI, не мешает питомцу | — Pending |
| mousedown/mouseup для поглаживания | Естественное взаимодействие | — Pending |
| Анимация кормления через CSS | Единый стиль с фазой 1 | — Pending |
| Смена emoji при поглаживании | Визуальный фидбек | — Pending |

## Phase Goal

Питомца можно покормить (выбор еды → анимация) и погладить (mousedown → реакция).

## Requirements

- PET-04: Механика кормления — выбор еды, питомец ест с анимацией
- PET-05: Поглаживание (mousedown/move) — питомец мурлычет, меняет выражение
- PET-13: Кнопки/UI для кормления (выбор еды)

## Success Criteria

1. Под питомцем появились кнопки с едой (3+ варианта)
2. Клик по еде → питомец ест (анимация + смена emoji)
3. При зажатии мыши на питомце — реакция (смена emoji)
4. При отпускании — возврат в idle
5. Анимации плавные, антистресс
