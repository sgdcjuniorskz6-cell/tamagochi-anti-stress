# Phase 3 Context: Система настроения

## Design Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Счетчик 0–100 | Просто, линейно, предсказуемо | — Pending |
| Старт с 50 | Нейтральное начало | — Pending |
| Таймер -1 каждые 5s | Медленное угасание, антистресс-темп | — Pending |
| +10 за взаимодействие | Заметный, но не мгновенный эффект | — Pending |
| Mood bar под питомцем | Визуальный индикатор без лишнего UI | — Pending |
| Graded emoji | Визуальная обратная связь через питомца | — Pending |

## Phase Goal

Питомец имеет настроение, которое меняется от взаимодействий и времени.

## Requirements

- PET-06: Система настроения — питомец грустит/радуется со временем
- PET-07: Взаимодействие поднимает настроение, бездействие — опускает
- PET-14: Индикатор настроения (визуальный статус)

## Success Criteria

1. Питомец начинает с нейтральным настроением (50)
2. Mood bar отображает текущий уровень
3. Бездействие: настроение медленно падает
4. Взаимодействия: настроение растёт
5. Разные emoji для высокого/низкого настроения
