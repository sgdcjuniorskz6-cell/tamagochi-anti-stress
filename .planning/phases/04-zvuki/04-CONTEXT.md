# Phase 4 Context: Звуки (Web Audio API)

## Design Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Web Audio API | Zero deps, синтезированные звуки | — Pending |
| OscillatorNode для мелодичных звуков | Чистый тон, антистресс | — Pending |
| AudioBuffer для шумовых звуков | Хруст/чавканье | — Pending |
| GainNode envelope | Плавное начало/конец без щелчков | — Pending |
| Ambient слой от настроения | PET-11, фоновая атмосфера | — Pending |

## Phase Goal

Все взаимодействия с питомцем имеют звуковое сопровождение через синтезированный звук.

## Requirements

- PET-08: Звук реакции на клик
- PET-09: Звук кормления
- PET-10: Звук поглаживания
- PET-11: Фоновый звук от настроения

## Success Criteria

1. Клик — короткий радостный звук (200ms)
2. Кормление — звук «чавканья» (300ms)
3. Поглаживание — низкий гул/мурлыканье, пока зажата мышь
4. Высокое настроение (>70) — мягкий фон, низкое (<30) — тишина
5. Все звуки приятные, не резкие
