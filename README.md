# 🐣 Тамагочи-антистресс

Интерактивный питомец для расслабления. Кликай, корми, гладь — питомец реагирует анимациями, звуками и настроением.

## ✨ Возможности

- **Реакция на клик** — прыжок + радостный звук
- **Кормление** — 4 вида еды (🍎 🍕 🍰 🍩)
- **Поглаживание** — мурлыканье при зажатии мыши
- **Настроение** — питомец грустит без внимания и радуется от заботы
- **Звуки** — синтезированные через Web Audio API
- **Антистресс-дизайн** — пастельные тона, плавные анимации

## 🛠 Стек

Чистый HTML / CSS / JS — zero dependencies.

## 🚀 Запуск

Открой `index.html` в браузере. Или [открой на GitHub Pages](https://sgdcjuniorskz6-cell.github.io/tamagochi-anti-stress/).
